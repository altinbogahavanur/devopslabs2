🔍 [SCEN-01 İpucu — Port Çakışması]

1. 8080 portunu hangi sürecin tuttuğunu görün:
   docker ps --filter publish=8080
   veya: sudo ss -tulpn | grep :8080

2. Çakışan 'port-occupier' konteynerini durdurup silin:
   docker rm -f port-occupier

3. İstenen 'fixed-port-web' konteynerini 8080 portundan başlatın:
   docker run -d --name fixed-port-web -p 8080:80 nginx:alpine
